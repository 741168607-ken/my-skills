# Picture Book Video（分级读物图文视频）

根据分级读物PDF + 朗读MP3，生成翻页式图文同步视频。

## 核心原则

**音频必须 100% 逐字复述绘本正文，绝不改写、省略、重排或增补任何词。**

**禁止使用 `text_to_audio_plus` 做正文配音**——它是 AI 演绎型工具，本质是把文本当场景去"表演"，无论怎么写 prompt 都会在个别词上省略/改写（已实测：会漏掉 bragged Tiger、said Elephant 等叙述词）。逐字复述唯一可靠的工具是**逐字合成型 TTS**。

**方案优先级（必须严格遵守，不可静默回退）：**
1. **唯一默认方案：edge-tts 逐字多角色 TTS**。凡是生成绘本视频，一律先走本方案。
2. **禁止用原始 MP3 原声做配音**。用户提供的 MP3 只用于"无 edge-tts 时的同步定位参考"，绝不直接当音轨，除非用户**明确要求**"保留原声"。
3. edge-tts 瞬时失败时（NoAudioReceived、网络抖动等）必须**重试或换音色**，不得因此改用原声；多次失败再向用户说明并征求是否改用原声。
4. 交付前必须核对：视频音轨是 edge-tts 合成的多角色配音，而非原 MP3。

## 配音工具：edge-tts（逐字 TTS，微软免费）

`pip install edge-tts`。逐字合成，给什么念什么，一字不差。内置多音色，可实现多角色。

**角色音色映射表（英文）：**

| 角色类型 | edge-tts 音色 |
|---------|--------------|
| 旁白（沉稳中年男性） | en-US-GuyNeural |
| 年轻/自信男性（如 Tiger、男孩） | en-US-ChristopherNeural |
| 低沉温和男性（如 Elephant、爸爸） | en-US-DavisNeural |
| 清脆/明亮女声 | en-US-AriaNeural 或 en-US-JennyNeural |
| 活泼男童 | en-US-EricNeural |

音色可用 `edge-tts --list-voices` 查询后选定。

## 执行流程

### 第一步：提取文本并按跨页分组

1. PyMuPDF提取PDF全部文字
2. 识别封面/版权页/故事跨页/结尾，跳过版权页和Glossary
3. 将叙述文本按跨页（spread）分组——一个跨页的所有文字作为一组
4. **排除对话框/气泡中的拟声词**（如"CROAK!"、"Tweet tweet tweet!"、"Quack!"等），这些不朗读

### 第二步：逐句归属角色并合成

**每个跨页单独处理**。把跨页文本严格按原文顺序切成句子，每句归属一个角色：

1. **叙述句 → 旁白**（en-US-GuyNeural）
2. **角色对话句（含其后的 said/asked/bragged/cried 叙述词）→ 对应角色音色**
   - 例 `"Look at me!" bragged Tiger.` → Tiger 音色整句念，**bragged Tiger 必须完整**
   - 例 `"You are fast," said Elephant.` → Elephant 音色整句念，**said Elephant 必须完整**
3. 每句用对应音色调 `edge_tts.Communicate(text, voice)` 逐字合成
4. 按原文顺序把所有句子音频拼接 → 该跨页完整配音

**铁律（不可妥协）：**
- **所有 said / asked / bragged / cried / called 等叙述词必须朗读，一字不省**
- 不得调换任何句子的顺序
- 不得加入原文以外的任何内容
- 不含任何中文、任何非正文文字（TTS 会一字不差念出，写入非正文必被念出）

### 第三步：拼接音频与视频

1. 每个跨页的配音段时长 = 该跨页视频显示时长
2. 将所有配音段按顺序拼接为完整 WAV
3. moviepy 按各段实际时长拼接对应跨页图片

## 视频剪辑规则

### 画面
- **单位**：以跨页（spread）为单位
- **开头**：封面停留约1.5~4秒
- **结尾**：最后一页停留至音频结束
- **跳过**：版权页、Glossary等非故事页面
- **分辨率**：1152×720，30fps

### 时长分配（核心规则）
- **每个跨页的视频显示时长 = 该跨页配音段的实际时长**
- 某跨页配音读完 → 立即切到下一个跨页
- **视频总时长 ≤ 音频总时长 + 5秒**（标题静默压到最短）

### 切换
- 跨页之间：1秒翻页转场动画+翻页音效（待实现）
- 开头封面→第一跨页：硬切

## 备选方案（无 TTS 时的严格同步）

若无法使用 edge-tts，改用**用户提供的原始朗读 MP3**：用 `mediakit-cli video asr-subtitles` 对 MP3 做带时间戳的语音转写，把每个跨页文本对齐到时间轴，得到精确翻页点，画面严格跟随朗读。此方案逐字（因为用原声）但音色为原始单人。
